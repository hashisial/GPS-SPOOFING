# GPS Spoofing Detection MERN Structure

This scaffold introduces a separate `client/` and `server/` architecture for a production-grade MERN implementation.

- `client/` is reserved for the React application, routing, hooks, reusable components, API clients, and page-level composition.
- `server/` is reserved for the Express API, MongoDB models, controllers, routes, middlewares, services, realtime sockets, and shared utilities.
- No business features are implemented yet. This is structure-only scaffolding.
